# دنانير — مصدر النظام

المصدر المعتمد للتسليم: **`D:\masal-vue`**. يحتوي هذا المجلد مصدر النظام للويب وتطبيق Android، وملفات البناء والاعتماديات المثبتة بالإصدارات، والاختبارات وأدلة التشغيل. الواجهات والطباعة والخدمات أجزاء من النظام نفسه وتستخدم قواعد العمل والصلاحيات المشتركة.

مرجع النشر الحالي بتاريخ **2026-10-18** هو Backend **`20261018-permissions138`**. نسخة Android المعتمدة **`1.4.10`**، ورمز إصدارها **24**؛ تعرض واجهة نقطة البيع المستضافة. تحديث الواجهة 140 يفصل إعدادات التطبيق والطابعات إلى تبويبين، ويعرض الطابعات المدعومة للقراءة فقط. تحديث الواجهة لا يغيّر إصدار Android أو إعدادات بيئة التشغيل.

## محتويات المشروع

| المسار | المحتوى |
| --- | --- |
| `frontend/` | مصدر Vue المشترك، أربعة مداخل للمدير والوكلاء ونقاط البيع وموقع الشركة، والأصول والاختبارات. |
| `backend/` | Laravel، قواعد العمل والصلاحيات، مخطط قاعدة البيانات وترقياته، واختبارات الخادم. |
| `android-pos/` | مصدر تطبيق Android وجسر النظام الأصلي ومكتبات الأجهزة اللازمة وGradle Wrapper. |
| `contracts/` | حصر مسارات API ووصف العمليات المسجلة وحدود تغطية مخططات الطلب والاستجابة. |
| `scripts/` | تجهيز الاعتماديات والبناء والاختبار وتشغيل PHP، بمسارات نسبية للمشروع. |
| `deployment/` | قوالب الاستضافة وأدوات الحزم وإجراءات النشر والصيانة. |
| `docs/` | أدلة التسليم والتفويض وفهرس الأرشيف. |
| `artifacts/android/` | APK الموقع المعتمد 1.4.10 للتسليم، بنسخة واحدة. |

ملفات `node_modules` و`vendor` ومخرجات `dist` و`build` والكاش ناتجة عن التجهيز والبناء؛ تعاد من ملفات التثبيت ولا تعد نسخًا أخرى من المصدر. النسخ السابقة وتقارير المراجعة مؤرشفة خارج المشروع. خزنة توقيع Android المشفرة مرفقة داخل `artifacts/private/`؛ ملف فتحها وأسرار التشغيل وقاعدة الإنتاج لها تسليم محمي منفصل.

## البدء على جهاز جديد

المتطلبات: **PowerShell 7، Node.js 22.12+، PHP 8.4.1+ وComposer 2.10+، Python 3.10+**. لبناء Android: **JDK 17 أو 21، Android SDK 35 وBuild Tools 35.0.0**. استعمل الإصدارات المثبتة في ملفات lock؛ لا تنفذ تحديث الاعتماديات عند التسليم.

من جذر المشروع:

```powershell
.\scripts\setup.ps1 -Target all
.\scripts\build.ps1 -Target all
```

التجهيز يثبت الاعتماديات ويتحقق من أدوات Android؛ لا ينشئ حسابًا أو يرحّل قاعدة بيانات. البناء يشغّل الاختبارات ويبني الواجهات الأربع ونسخة Android للتطوير افتراضيًا. التفاصيل وإعداد قاعدة محلية جديدة في [دليل التسليم](docs/HANDOVER.md).

لتشغيل بيئة محلية مستقلة بعد إعدادها، افتح طرفيات منفصلة:

```powershell
npm run backend:serve
npm run dev:admin
npm run dev:agents
npm run dev:pos
npm run dev:public
```

استخدم `admin.localhost:5173` و`agents.localhost:5174` و`pos.localhost:5175` و`public.localhost:5177`. اختلاف المضيف يعزل جلسات البوابات؛ اختلاف المنفذ وحده لا يعزل Cookies.
