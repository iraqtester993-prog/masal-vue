الرابط وحده لا يمنح صلاحية. Laravel يفحص العضوية والإجراء ونطاق الحساب وحالة السلسلة في كل طلب، بما فيه الملفات والتصدير. نقطة البيع تتبع أي مستوى من الوكلاء. الموظف يخضع لنطاقه الممنوح؛ وجوده ضمن حساب أعلى لا يمنحه بيانات ذلك الحساب تلقائيًا.

بيانات العمل واللغة والمظهر تحفظ في السيرفر؛ الجلسة تستخدم Cookie خاصة بالمضيف وCSRF. حالة العرض المؤقتة تبقى في الذاكرة، دون حفظ بيانات الحسابات أو رموز الدخول أو التفضيلات في localStorage أو sessionStorage أو IndexedDB. الأصل محفوظ للمراجعة؛ نقل المصدر لا يعني مسح بيانات المتصفح القديمة أو استيرادها تلقائيًا.

## التشغيل المحلي

المتطلبات: Node.js **22.12+** وPHP **8.4.1+** حسب `composer.lock`. أداة `scripts/backend.ps1` تختار PHP المحدد في `MASAL_PHP` أو النسخة المستقلة داخل `.codex/runtimes/masal-php`؛ لا تعتمد على XAMPP PHP 8.2 ولا تعدل إعداداته. جهّز اعتماديات Composer وبيئة محلية وقاعدة مستقلة باستخدام قوالب `backend/.env*.example` قبل تشغيل Laravel.

من جذر المشروع، بعد تجهيز البيئة:

```powershell
npm --prefix frontend ci
npm run backend:serve
```

وفي طرفيات منفصلة:

```powershell
npm run dev:admin     # http://admin.localhost:5173
npm run dev:agents    # http://agents.localhost:5174
npm run dev:pos       # http://pos.localhost:5175
npm run dev:public    # http://public.localhost:5177
```

استخدم مضيفًا مختلفًا لكل بوابة؛ اختلاف المنفذ وحده لا يعزل Cookies. Vite يمرر API وCSRF إلى `127.0.0.1:8000` ويضيف ترويسة البوابة للتطوير فقط. الإنتاج يحدد البوابة من المضيف المعتمد. تفاصيل الواجهة في [frontend/README.md](frontend/README.md).

## التحقق قبل النشر

```powershell

& ./scripts/backend.ps1 vendor/bin/pint --dirty --format agent

```

الفحص النهائي لهذه النسخة: **SQLite: 561 حالة، 557 نجاحًا، 4 حالات تخطٍ فعلية، 5055 تأكيدًا؛ MariaDB: الأعداد نفسها و5057 تأكيدًا؛ Vue: 154 اختبارًا ناجحًا وأربعة أبنية ناجحة**. وقبول cPanel المعزول نجح منفصلًا: الاستعادة المباشرة **اختبار ناجح و34 تأكيدًا**، والعامل الكامل **اختبار ناجح و68 تأكيدًا**. حالات التخطي في المجموعة العامة لا تعد نجاحًا. الاختبارات والبناء لا تثبت المطابقة البصرية الكاملة أو جاهزية جميع إعدادات المزودين؛ حدود كل فحص في [سجل التحقق](docs/FULL_SYSTEM_07_VERIFICATION.md).

النشر يعمل على **PHP 8.5.11 وLaravel 13.34**؛ تطابقت **609 ملفات**، وبلغ المخطط **94 جدول InnoDB**. حفظت بيانات **59 جدول أعمال سابقًا**، وبقي حسابان ومستخدمان كما قبل النشر. نجح **1746/1746 فحص HTTP**، ثم تأكدت مطابقة HTML والأصول المبدئية بعد UI01؛ حدود مراجعة المتصفح والتجارب الخارجية موثقة في سجل التحقق.

GitHub Actions ينفذ التحقق فقط، ولا ينشر إلى cPanel أو GitHub Pages. `npm run build:legacy` بناء مرجعي مستقل؛ لا يدخل حزمة الإنتاج.
