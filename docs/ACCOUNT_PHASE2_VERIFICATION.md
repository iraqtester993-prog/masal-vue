نجح 26 فحص HTTP عبر HTTPS وجلسات فعلية مستقلة. شملت دخول المدير والوكلاء والنقطة، كامل تدرج الوكلاء، POS تحت كل مستوى وكيل، حدود القوائم والعدادات، رفض شبكة أخرى، منع تعديل الذات وإنشاء الشبكة من POS/employee، التعديل و409، وملفات خاصة برفع multipart وتنزيل بايتات الملف ومنع تنزيله من شبكة أخرى وحذفه بإصدار. نجح كذلك منع حذف نوع مرتبط، سحب جلسة الموظف عند إيقاف نوعه، إلغاء المعرف القديم عند تبديله، سحب جلسات التابعين عند إيقاف الأب، الدخول الجديد بعد التفعيل، وlogout/CSRF والكوكيز الآمنة دون Domain مشترك.
