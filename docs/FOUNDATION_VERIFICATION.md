## نتائج التحقق

| الفحص | النتيجة وحدود الدليل |
|---|---|
| اختبارات الباك النهائية | `npm run backend:test`: **74 اختبارًا و343 assertion ناجحة** بعد تحديد InnoDB وتنظيف العينة المحلية |
| اختبارات الواجهة | **17 اختبارًا ناجحًا** |
| البناء | بناء البوابات الثلاث وبناء legacy ناجحان؛ legacy مستبعد من حزم البوابات الجديدة |
| تحقق المصدر القديم | 213 ملف مصدر legacy مطابق بالبايت للنسخة الاحتياطية السابقة للنقل |
| استعادة المصدر | فك النسخة الأصلية في مجلد منفصل ثم `npm ci` و`npm run build` ناجحان؛ هذا لا يثبت استعادة قاعدة التشغيل |
| اعتماديات الاستضافة | تثبيت 77 حزمة إنتاج وفحص Composer للمنصة وmigrations وتهيئة الصلاحيات و`optimize` ناجحة |
| المحرك الفعلي | **16 فحصًا ناجحًا** على MariaDB: InnoDB والشجرة وPOS تحت أي مستوى وعزل الشبكات والتدقيق وإلغاء إنشاء مكرر؛ `rolled_back=true` وجميع عينات الاختبار زالت |
| إنشاء حساب من Vue | إنشاء العينة المحلية عبر نموذج المدير أعاد 201 وظهرت في قائمة الحسابات؛ ليست عملية إنشاء وكيل تجاري على الاستضافة |
| الدخول على HTTPS | دخول المدير الفعلي وقراءة الحسابات وظهور إجراء إنشاء تابع، ثم الخروج والعودة للدخول، نجحت في المتصفح |
| عزل البوابات الفعلي | أثناء دخول المدير، فتح `/accounts` في الوكلاء وPOS أعاد إلى صفحة دخولهما؛ بيانات المدير رفضت في بوابة الوكلاء برسالة عامة |
| كوكيز البوابات | لكل مضيف اسم جلسة مختلف؛ `Secure` و`HttpOnly` و`SameSite=lax`، دون `Domain` مشترك؛ XSRF cookie آمنة وقابلة لقراءة العميل لإرسال CSRF |
| HTTP الأساسي | البوابات الثلاث: `/login` 200 و`/sanctum/csrf-cookie` 204 و`/api/v1/auth/me` دون جلسة 401 JSON؛ إرسال `X-Masal-Portal: admin` لا يحقق الدخول |
| CSRF الفعلي | POST إلى دخول المدير ببيانات JSON فارغة، مع Accept وOrigin، دون رمز CSRF: **419 JSON** |
| حدود Apache | الدخول المباشر إلى `masal-api.php` وasset مفقود وAPI خارج التوجيه: 404؛ طلب `.env`: 403 |
| التخزين في الواجهة الجديدة | لا localStorage أو sessionStorage أو IndexedDB لبيانات الأعمال/الدخول في المصدر النشط؛ لم تمسح بيانات المتصفح القديمة التي لم تحصر بعد |

اختبار MariaDB استخدم معاملة تلغى بالكامل، وليس استعادة نسخة احتياطية. اختبارات HTTPS لا تشمل بعد تسجيل دخول مستخدم صحيح من كل مستوى أو تشغيل حسابين مختلفين متزامنين؛ تغطية قواعد المستويات والشبكتين موجودة في اختبارات الباك.

## العمل المتبقي

استعادة كلمة المرور، وتعديل الحسابات ونقل تبعيتها وإدارة الإيقاف والتفويض من الواجهة؛ والمنتجات والمخزون والأسعار والمبيعات والمحافظ والتقارير والطباعة والتكاملات. كذلك اختبار استعادة قاعدة البيانات والملفات، والرجوع بين الإصدارات، والأحمال والبريد وjobs، ثم قبول الإنتاج. الكود القديم محفوظ للمراجعة والنقل؛ لا يحمل في البوابات الجديدة، ولا يعد حذفه أو حذف بيانات المتصفح منجزًا.
