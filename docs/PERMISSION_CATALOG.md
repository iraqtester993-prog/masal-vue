# كتالوج صلاحيات المصدر الحالي

تاريخ الاستخراج: 2026-10-06. المصدر: src/services/access.js.

هذا جدول مرجعي للمصدر القديم المحفوظ في `frontend/legacy/src`. كتالوج السيرفر المنفذ بعد الدفعة الثالثة يحتوي 38 مفتاحًا فقط؛ حدوده وفروق الأدوار في [PERMISSION_MATRIX.md](PERMISSION_MATRIX.md)، ولا تعني الصفوف أدناه أن البيع أو المالية أو بقية العمليات نُفذت.

تم تشغيل وحدة الصلاحيات وحدها في سياق Node مع شبكة اصطناعية، دون تحميل التطبيق أو قراءة التخزين أو استخدام بيانات دخول. الأعمدة نتيجة can الفعلية الافتراضية لهذه العينة، بما فيها منع الأسلاف؛ ليست سياسة الإنتاج المعتمدة ولا تغني عن Policies واختبارات السيرفر. لا overrides أو permission profiles في العينة.
