## حفظ المحتوى الأصلي

نُقل القاموس المرجعي غير التجريبي: آسياسيل و28 فئة، بأسمائها ومعرّفاتها الأصلية من `frontend/legacy/src/services/order-parser.js` وطريقة تهيئتها في `multi-orders.js`. لا تنقل شركة العرض التجريبي أو بطاقتها أو الوكلاء والمحافظ التجريبية. لم تستورد بيانات المتصفح غير المحصورة.

أسعار البيع الدنيا والحدود غير المعينة في القاموس تبقى null/غير معينة في DB؛ سبع فئات بلا قيمة اسمية معروفة تبقى قيمتها null أيضًا. لم تتحول القيم الاسمية إلى تكلفة شراء. الجدول يحتفظ بتنسيق الأصل الذي يظهر القيم المالية الفارغة كـ0، ومعاينة التفاصيل تعرض غير المحدد كشرطة؛ ظهور 0 في الجدول ليس تسعيرًا تجاريًا محفوظًا. حفظ فئة جديدة أو تعديل مرجعية يتطلب ضبط قيمها الموجبة وحد يومي واحد صالح. تهيئة القاموس مستقلة عن seed الصلاحيات وتكرر بأمان؛ معرّفها الداخلي لا يقبل من API ولا يظهر فيه، وتعارض بيانات موجودة لا يمحوها.
