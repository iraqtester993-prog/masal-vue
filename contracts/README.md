# مراجع API

`API_ROUTE_CATALOG.json` حصر مولد من مسارات Laravel الحالية. يثبت وجود الطريقة والمسار والوسائط المسجلة، ولا يثبت بمفرده التفويض أو صحة المعاملة أو جاهزية المزود. يُحدّث مع تغيّر المسارات، من `route:list --json` وبعد تصفية API وSanctum، دون الاتصال ببيانات الإنتاج.

`openapi.yaml` فهرس حالي لجميع الطرق والمسارات المسجلة، مع معلمات المسار والمتحكم والوسائط لكل عملية. الحصر الحالي: **260 سجل مسار، و224 عنوان URI، و382 طريقة ومسار عند احتساب HEAD**. لا يخمّن أجسام الطلبات أو الاستجابات؛ تعريفها الدقيق في كود التحقق والمتحكمات والموارد. النسخة التفصيلية التاريخية السابقة محفوظة في أرشيف الدسكتوب.

مرجع سلوك كل عملية هو المسار وFormRequest والمتحكم وResource والخدمة واختباراتها في `backend/`. يعمل API بجلسة Cookie وCSRF ضمن أصل البوابة نفسها؛ مفاتيح تكامل المزودين ليست مفاتيح دخول إلى بوابات النظام.

لتحديث الفهرس من جذر المصدر بعد تثبيت الاعتماديات:

```powershell
python contracts/update_contract.py --php 'C:\PHP\php.exe'
```

يستخدم المولّد بيئة اختبار وSQLite في الذاكرة وكاشًا مؤقتًا؛ لا يتصل بقاعدة العمل. للاستعراض المحلي:

```powershell
& .\scripts\backend.ps1 artisan route:list --path=api
& .\scripts\backend.ps1 artisan route:list --path=sanctum
```

تفاصيل التفويض الحالية في [دليل الصلاحيات](../docs/PERMISSIONS.md)، وإعداد البيئة في [دليل التسليم](../docs/HANDOVER.md).
