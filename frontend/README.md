# واجهة دنانير

Vue **3.5.43** وVue Router **4.6.3** وVite **8.3.2**، وفق `package-lock.json`. مصدر واحد للمكونات والأنماط وقواعد العرض، مع أربعة مداخل مستقلة:

| المدخل | التطوير المحلي | البناء | الإنتاج |
| --- | --- | --- | --- |
| `admin` | `http://admin.localhost:5173` | `dist/admin/` | `admin.dananir-iq.com` |
| `agents` | `http://agents.localhost:5174` | `dist/agents/` | `agents.dananir-iq.com` |
| `pos` | `http://pos.localhost:5175` | `dist/pos/` | `pos.dananir-iq.com` |
| `public` | `http://public.localhost:5177` | `dist/public/` | `dananir-iq.com` |

## التشغيل والبناء

من جذر المشروع:

```powershell
.\scripts\setup.ps1 -Target frontend
.\scripts\build.ps1 -Target frontend
```

أمر البناء يتحقق من الواجهة ويبني المداخل الأربعة. يمكن تشغيل مدخل واحد عبر `npm run dev:admin` أو `dev:agents` أو `dev:pos` أو `dev:public`. Laravel المحلي يعمل على `127.0.0.1:8000`؛ يمرر Vite طلبات API وCSRF إليه. تغيير الهدف المحلي متاح عبر `MASAL_BACKEND_URL` في إعداد تطوير خاص. الإنتاج يقدم ملفات البناء ولا يحتاج خادم Vite دائمًا.

عند العمل داخل `frontend/`، الأمر `npm run build` يبني البوابات الثلاث؛ `npm run build:public` يضيف موقع الشركة. `npm test` يشغّل اختبارات الواجهة.

## أماكن التعديل

`src/modules/` يجمع صفحات كل مجال وحالته وطلبات API. `src/shared/` للمكونات والأنماط والأدوات المشتركة. `src/layouts/` لأطر العرض، و`src/router/` للمسارات والتفويض المرئي. `portals/` يحتوي مداخل البناء؛ لا تنسخ الوظائف المشتركة بين البوابات.

ألوان الوكيل والمظهر تستخدم متغيرات الهوية المشتركة. بيانات الصفحة السابقة تبقى أثناء التحديث المناسب، مع التحقق من صلاحيات الهوية الحالية. لا يعوض كاش الواجهة استجابة الخادم الخاصة بالأرصدة أو نتيجة عملية مالية. استجابة فشل الطباعة لا تنشئ بيعًا آخر تلقائيًا.

## الجلسات والتفويض

Laravel هو مرجع الجلسة والصلاحيات والنطاق. إخفاء المسارات والأزرار في Vue لتحسين العرض، ويتحقق الخادم مجددًا من كل طلب. إعدادات التطبيق والطابعات تعرض الأقسام الممنوحة فقط، وتختفي البيانات المقيدة عند سحب صلاحيتها. موقع الشركة العام لا يحمل إطار الإدارة ولا يفتح واجهات الحسابات.

تجدد الواجهة المنشورة يصل إلى APK الحالي لأن التطبيق يعرض بوابة نقطة البيع. تعديل الجسر الأصلي أو موارد Android أو صلاحياته يتطلب بناء APK وتوقيعه. راجع [دليل Android](../android-pos/README.md) و[دليل التسليم](../docs/HANDOVER.md).
